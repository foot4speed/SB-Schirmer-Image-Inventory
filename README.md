# SB Schirmer Image Inventory Engine

## Purpose

This project inventories and analyzes food and product images stored in Google Drive.

The system scans a Google Drive folder, identifies each image using the OpenAI API, and records structured metadata in a Google Sheet.

## Current Status

Version 1.0

Phase 1:
- Inventory images
- Analyze images with AI
- Store metadata in Google Sheets
